# Alva Full Skill 第二阶段优化

## 1. 目标
减少重复声明和无效准备，改善 Thesis 查询衔接，恢复 Worldline 辅助研究，并让 Automation 失败后的调试更有效。

## 2. 最终改动
- 移除通用投资免责声明及固定分析师开场；保留来源核验、真实风险与数据缺口、交易授权、Thesis 发布确认，以及作者原文。
- 根据引用后的问题读取作者、标的、相关观点或 Signals；复用真实身份，保留引用版本，读操作不进入发布或更新流程。
- 在能力入口和 search.md 介绍 Worldline：主题、关键词、实体、人物归属、原文、访谈和事件信息。模型自主决定是否查询及深度，独立读取尽量并行，保留部分成功结果。
- 回答自然附上原始来源链接，以节目、频道或标题作链接文字；有可靠播放时间时标注，不能凭空构造定位。
- 区分来源发布时间、事件时间和聚类成员时间；入库时间仅用于内部检索参数，不用于面向用户的日期或新鲜度判断。长转录在脚本内选取相关段落并保留上下文。
- 补充 SDK 1.13.0 的可选 matchContributions 及 entityIds 与 attribution 联合过滤；保留旧宿主回退、分页和大结果集处理约束。
- 耗时 Automation 失败后先调试受影响阶段，诊断不写正式 Feed 或发通知；修复后完整运行最终代码。模型结果先检查 stopReason 和 errorMessage，再提取或解析正文，保留原始错误。

## 3. 实现与边界
沿用 SKILL.md、现有 references 和 alva run，版本为 v1.26.5。Worldline 补充结构化数据与 X 搜索，不要求每题查询。保留三个官方 Automation 快速路径及上游 Thesis 预览/更新修复；无新运行时、接口或权限变更。

## 4. 文件范围
SKILL.md；alpi、feed-lifecycle、fintwit、request-routing、search、thesis、user-facing-prose、api/release references；已有文档、场景和 mutation 检查。

## 5. 验证结果
- 文档检查 110/110（1282 项）、mutation 49/49、durable-agent 5/5。
- Worldline 示例执行检查 34 项；一次生产只读示例约 2.35 秒返回 5 条，不能据此承诺真实聊天速度。
- Full/Slim 五份模型结果示例的最终错误处理探针 35 项通过；git diff --check 通过。
- 此次只合并变更说明，产品文件未变；以上为实现阶段结果，未因整理文档重新跑全套测试。

## 6. 发布依赖
[Skills #657](https://github.com/alva-ai/skills/pull/657)。合并后发布 v1.26.5，再按正常流程更新消费者生产锁。作者 slug 依赖 [Gateway #1086](https://github.com/alva-ai/alva-gateway/pull/1086) 和 [Toolkit #197](https://github.com/alva-ai/toolkit-ts/pull/197)。Worldline 异步示例要求 SDK 1.12.0+ 和宿主 relay；新方法要求 SDK 1.13.0 与 Gateway #1085 实际部署，合并不代表上线。

## 7. 兼容与交付状态
无 API 或数据库变更；普通投资免责声明移除是经产品/法务确认的体验变化。配套 Slim 为 [SDK #399](https://github.com/alva-ai/sdk-monorepo/pull/399)。未执行生产发布或配置修改。

## 8. 待验证
已有四条 Full/Slim 作者追问正确衔接正文与作者，但均缺用户要求的链接，且未覆盖 Person、标的、Related、Signals 和分页。Worldline 早期 Full Eval 显示有用召回及混合的速度/质量结果；最终日期、长转录、联合查询和 Slim 效果仍需定向 Eval。Automation 的真实耗时收益也未确定。
