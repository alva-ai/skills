# Alva Full Skill 优化（第一步发布）

## 1. 目标
改善日常投资对话、Thesis 研究与读取衔接，减少重复声明和无效准备。

## 2. 本轮改动
- 移除通用投资免责声明和固定分析师开场；保留证据核验、实际风险、交易授权、Thesis 发布确认及作者原文。
- 引用后的追问按作者、标的、相关观点或 Signals 分流，复用已核实身份并保留引用版本。Person slug 缺失时按已确认名称解析，不要求新接口。
- 恢复 Worldline 辅助研究：介绍主题、关键词、实体、人物、访谈及事件查询，由模型选择查询与深度，独立读取尽量并行，保留部分结果。
- 使用原文链接和可靠播放时间；区分发布时间与事件时间，入库时间仅作内部检索参数；长转录在脚本内选取相关段落并保留上下文。
- 补充 SDK 1.13.0 可选 matchContributions 和联合过滤用法，保留旧宿主回退、分页及大结果选择。
- Automation 失败后先调试受影响阶段，诊断不写正式 Feed 或通知，修复后完整验证最终代码；提取结果前核对 stopReason 和 errorMessage，不吞掉原始错误。

## 3. 设计与兼容
沿用现有能力入口、references 和 alva run。Worldline 非强制，不替代结构化数据或 X 搜索。保留三个官方 Automation 快速路径、发布确认、交易授权及上游 Thesis 修复。

## 4. 文件范围
SKILL.md；alpi、feed-lifecycle、fintwit、request-routing、search、thesis、user-facing-prose、api/release references；现有文档、场景及 mutation 检查。候选版本 v1.26.5。

## 5. 验证
文档 110/110（1282 项）、mutation 49/49、durable-agent 5/5；Worldline 示例执行 34 项、模型结果错误处理探针 35 项通过。一次生产只读示例约 2.35 秒返回五条，不代表真实聊天速度。此次发布整理只改 changelog，产品内容未变，未重复跑全套测试；git diff --check 通过。

## 6. 发布顺序
合入并发布 v1.26.5，再更新消费者生产 Skill 锁并构建镜像。本 PR 可独立发布，不依赖作者 slug 新字段。配套 Slim 为 SDK #399，共享表达偏好为 Sandbox #396。

## 7. 运行条件
Worldline 异步示例要求 SDK 1.12.0+ 与宿主 relay；可选新接口要求 SDK 1.13.0 和 Gateway #1085 实际部署，合并不等于上线。无数据库迁移或新增权限。

## 8. 验收边界
已有 Full/Slim 作者追问通过身份衔接，但仍缺用户要求的链接，未覆盖全部非空 Person、标的、Related、Signals 和分页场景。最终 Worldline 时间、转录、联合查询及真实延迟仍需定向 Eval；Automation 局部调试的真实提速也待验证。此 PR 不代表生产部署完成。
