# Earnings KOL Radar

Single-page post-earnings recap on Alva — one URL per (ticker × earnings event). Layout: Hero (always visible) + 5 tabs. **Narrative is the default-active tab.**

## Container-level copy (outside the iframe)

Generated by the alva skill on each new instance; later editable by hand. The frontmatter `description:` above is the *skill trigger* — not the same as the playbook Description below.

- **Description** — one short paragraph (≤2 sentences) describing what this playbook delivers and when to read it. Audience: someone scanning the marketplace card. Don't restate the ticker — instances are per-(ticker × event), so the Description is the same template-wide copy.
- **README** — full why / what / how / when. Reference (don't restate) the iframe; pointers to §Feed pipeline + §Hero / §Tabs. Keep operator-only detail (schema, "Don't touch") out.

## In-iframe explanation budget — keep the reading threshold low; structure carries the meaning

- **Default** — let labels, number tiles, banner enums, and verbatim KOL / mgmt quotes speak for themselves. No prose patches.
- **Tab / Widget body** — only for content the user MUST see. On this template that's the `READ` line, the regime banner, and `WHY THE MOVE` drivers.
- **Info tooltip / popup (collapsed by default)** — explanatory copy: regime-label / tape-state definitions, KOL-vs-sellside boundary, how bull/bear pairing works, what `VS L4Q AVG` is normalized against. Don't inline these into the tab.

## Hero

- **Header bar** — ticker · company · fiscal · report date · last refresh + "How this works". Data: `event/snapshot` + `synthesis.generated_at`.
- **Regime banner** — left: regime label (`BEAT-AND-FADE` / `BEAT-AND-EXTEND` / `SQUEEZE` / `MISS-AND-RIP` / `MUTED`) + day-of % + `$open → $close`. Right: since-print % + tape-state tag (`EXTENDING` / `RECOVERING` / `FADING` / `STALLING`) + `HOVER · PRICE TAPE` hint (banner reveals price-tape chart on hover). Data: `event/price` + `synthesis.regime_label` + `synthesis.tape_state`.
- **READ line** — one verbatim causal sentence prefixed `READ`. Only prose in Hero — must carry the load-bearing mechanism. Data: `synthesis.key_delta`.
- **6 number tiles** — `EPS SURPRISE` (% · $actual vs $consensus), `REVENUE SURPRISE` (% · $actual vs $consensus), `DAY-OF REACTION` (% · $open→$close), `CUMULATIVE` (% since-print · latest $), `VS L4Q AVG` (×ratio + qualitative tag, e.g. `0.6× Muted`), `VS SPY (DAY-OF)` (pp + tag, e.g. `Underperformed market — stock-specific weakness`). Data: `event/snapshot` + `event/price`.
- **NEXT WATCH** — single-line trigger under tiles. Data: `synthesis.watch_list[0]`.

## Tabs

- **Narrative (default)** — numbered `WHY THE MOVE` drivers (each cites a specific number + causal mechanism) + remaining forward catalysts. Data: `synthesis.why_move` + `synthesis.watch_list[1..]`.
- **KOL sentiment** — independent / fintwit voices only (sell-side analyst changes go to the Sell-side tab). `TRACKING:` row of contributing handles, then per-author cards in 2 cols labeled `BULL` / `BEAR` / `NEUTRAL` from author stance, each verbatim with ONE 4-15 word phrase wrapped in `<mark>...</mark>`. Data: `synthesis.kol_highlights[]` (idx-keyed: text with `<mark>`, `author`, `stance`) + `synthesis.tracked_handles[]`.
- **Prepared remarks** — verbatim press-release lines + "Check original ↗". Data: `synthesis.mgmt_verbatim` + `event/sec_release.url`.
- **Sell-side** — shift strip (avg PT, ↑/↓ counts, biggest move) + per-firm table. Data: `synthesis.sellside_thesis`.
- **Theme peers** — 4 cards (ticker + why-mechanism). Data: `synthesis.read_through`.

## Feed pipeline (one `feed.run`)

- `event/{snapshot, price, sec_release}` ← `earnings-calendar` / `kline` / `sec-earnings-release`. `price` carries day-of OHLC, post-print path, L4Q earnings-day history, and SPY same-session series.
- `pt/changes` ← `searchGrokX` (firms × month). `news/items` ← `searchBrave`. `social/topical` ← `searchGrokX` (`$TICKER` cashtag). `social/whitelist` ← `getTwitterBackfill` per handle, last 7d, post-filtered.
- **KOL dedup + curate before ADK** — merge `topical` + `whitelist`, dedup by URL + `author|text-80-char` fingerprint, sort by engagement, cap top-N → surviving handles populate `tracked_handles`. **Drop**: company's own X handle; sell-side firm handles (`@Citigroup` / `@JPMorgan` / `@GoldmanSachs` / `@Evercore` / etc., route via `pt/changes`); link-only / retweet-only posts; posts with <15 words of original commentary; generic announcement headlines (`released financial results`, `earnings call live`).
- `synthesis/record` ← `adk.agent` produces all `synthesis.*` fields above. `synthesis.tweet_thread` (10 tweets, ≤270 chars) is generated but consumed by a separate skill — not rendered on this page.
- **Deploy**: 3h cron during the 72h post-print window.

## Don't touch

- Schema (`regime_label`, `tape_state`, `key_delta`, `why_move`, `kol_highlights`, `tracked_handles`, `mgmt_verbatim`, `sellside_thesis`, `read_through`, `watch_list`, `tweet_thread`) is bound field-by-field to HTML — renaming silently blanks the section.
- Prompt rules:
  - `regime_label` / `tape_state`: pick from the fixed enums in Hero — don't invent new labels (banner styling keys off the values).
  - `key_delta`: ONE verbatim causal sentence (no list, no headline paraphrase) — only Hero prose, must carry the mechanism.
  - `why_move` drivers: cite a specific number + causal mechanism.
  - `kol_highlights`: verbatim text; stance ∈ `BULL` / `BEAR` / `NEUTRAL`; ONE 4-15 word `<mark>` per card carrying one of — **result/KPI from this print** vs consensus/prior/guide (`$0.38 missing $0.39`, `18A yields to 65%`); **forward setup** — guide/capacity/catalyst (`under-shipping persists through 2026`); **directional call** — PT/target/position (`raised PT to $115 from $105`); **positioning read** — consensus divergence (`moves start when no one is paying attention`). **Never**: tangential numbers (macro, pre-print IV, unrelated spend), corporate boilerplate, retweet headlines, link-only.
  - No invented numbers; tweet ≤270 chars; respect banned-phrases list.
- Update `pickEventRow` date prefix (e.g. `"2026-03"`) on every clone — otherwise grabs the wrong quarter silently.
